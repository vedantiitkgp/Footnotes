# Gem Head

Turn your travel photos into a richly written memoir — complete with a route map, AI postcards, voiceover audio, and ambient soundscapes.

---

## What it does

Upload photos from a trip, add a short description, pick a writing style, and Gem Head generates:

- **Travel memoir essay** — 700–1000 words in literary, journal, journalistic, or poetic style, streamed live as it's written
- **Route map** — interactive Leaflet map with animated trail and pulsing pins, geocoded from every place name mentioned in the essay
- **AI postcards** — 3 Imagen-generated postcard images based on narrative gaps in the story
- **Voiceover** — full essay read aloud using Gemini TTS (Charon voice), with word-by-word highlight synced to playback
- **Ambient soundscapes** — procedural Web Audio soundscape (coastal, mountain, jungle, desert, urban) that plays while the voiceover runs
- **What If? section** — 3 dry, witty hypotheticals about your trip generated by Gemini
- **Photo reel** — original photos in a slide-in panel with a full lightbox and keyboard navigation
- **History page** — past memoirs persist for 7 days and are accessible via `/history`

---

## Tech stack

| Layer | Stack |
|-------|-------|
| Frontend | React 18, Vite, React Router, Framer Motion, Leaflet |
| Backend | Node.js, Express, SSE streaming |
| AI | Gemini 2.5 Flash (essay, analysis, TTS, What If), Imagen (postcards) |
| Vision | Google Cloud Vision API (optional — landmarks, faces, signs) |
| Maps | OpenStreetMap Nominatim (reverse + forward geocoding) |
| EXIF | `exifr` (GPS coordinates, timestamps from photo metadata) |

## Setup

### 1. Clone and install

```bash
git clone <repo>
cd gem-head
npm run install:all
```

### 2. Environment variables

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key

# Optional — enables landmark/face detection via Cloud Vision
GOOGLE_VISION_API_KEY=your_vision_api_key
```

Get a Gemini API key at [aistudio.google.com](https://aistudio.google.com).

### 3. Run in development

```bash
npm run dev
```

- Frontend: `http://localhost:5173`
- Backend: `http://localhost:3001`

---

## Docker (production)

```bash
docker compose up --build
```

The app runs on port `3001`. Nginx or a reverse proxy should handle SSL termination.

## How the generation pipeline works

```
Upload photos
     │
     ├── Gemini vision analysis   (locations, landmarks, people, moods)
     ├── Google Cloud Vision      (optional: landmarks, faces, signs)
     └── EXIF extraction          (GPS coords → reverse geocode, timestamps)
                │
                ▼
        Essay streaming (SSE)
                │
                ├── Extract all locations from essay text  ─┐
                └── Imagen postcards (3×)                   │ parallel
                                │                           │
                                ▼                 ←─────────┘
                        Merged location list → map
                                │
                        Gemini TTS voiceover
                                │
                        Gemini What If? (3 Q&As)
                                │
                        memoir.json saved to disk
```

Sessions (photos + generated assets) are kept for **7 days** then automatically deleted.
